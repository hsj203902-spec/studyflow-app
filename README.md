# StudyFlow — 아이폰·맥북용 학습 진도 관리 웹앱

학습량 추적 웹앱. Xcode, Notion, 유료 서비스, 외부 라이브러리 없이 동작합니다.

## 주요 기능

- 과목 → 폴더 → 학습 목표 계층 (폴더 다중 중첩 가능)
- 처음 시작하면 과목과 목표가 비어 있으며, 직접 추가할 수 있습니다.
- 학습 항목 추가·수정·삭제, 누적 진도 +/- 버튼, 날짜별 학습량/메모 기록 및 삭제
- 강의 수·문제 수·페이지 수 등 단위를 구분한 진행률
- 각 항목별 마감일, D-day, 휴식 요일을 제외한 하루 권장 학습량 계산
- 과목별·일자별 기록과 간단한 최근 7일 그래프
- 기기 내 localStorage 자동 저장 / JSON 내보내기·가져오기
- PWA 매니페스트, 서비스 워커(오프라인 정적 파일 캐시), iPhone 홈 화면 아이콘

## iPhone에 설치 (추천: GitHub Pages)

1. GitHub에서 새 저장소 `studyflow`를 만듭니다.
2. 이 폴더 **안의 파일과 하위 폴더**를 저장소 **최상위**에 업로드합니다. `index.html`이 최상위에 있어야 합니다.
   - GitHub 웹의 **Add file → Upload files**를 이용할 수 있습니다.
   - `.github/workflows/`는 필수가 아니며, 이 프로젝트에서는 별도 빌드 도구가 필요 없습니다.
3. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**를 선택합니다.
4. **Branch: main, Folder: /(root)**를 선택 후 저장합니다.
5. 게시된 주소(`https://사용자명.github.io/studyflow/`)를 iPhone **Safari**에서 엽니다.
6. Safari **공유 → 홈 화면에 추가 → 웹 앱으로 열기 → 추가**를 선택합니다.

> GitHub Pages는 저장소 설정과 계정 요금제에 따라 공개 저장소가 필요할 수 있습니다. **코드만 공개**되고 학습 기록은 웹서버로 업로드되지 않습니다. 사용 기록은 브라우저 저장소에만 남습니다.

## Mac에서 사용

게시된 GitHub Pages 주소를 Safari로 열고 **파일 → Dock에 추가**를 선택할 수 있습니다.
또는 압축을 풀고 `index.html`을 브라우저로 열어 간단히 확인할 수 있습니다. 단, `file://` 사용은 브라우저별 저장/오프라인 동작이 달라 권장하지 않습니다.

개발용 로컬 서버가 필요하면 프로젝트 폴더에서:

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## 중요: 데이터 보관 방식

- iPhone과 Mac은 **각자 별도의 데이터**를 가지고 자동 동기화되지 않습니다. 두 기기에서 쓰려면 설정 → JSON 백업/불러오기로 수동 복사하세요.
- 앱을 삭제하거나 Safari의 웹사이트 데이터를 삭제하면 학습 기록이 사라질 수 있습니다. 주기적으로 설정 → JSON 백업을 권장합니다.
- 오프라인 사용은 HTTPS/localhost에서 앱을 **한 번 온라인으로 정상 로드한 뒤** 정적 파일이 캐시된 경우에 가능합니다. 사파리의 캐시 정책이나 사용자가 데이터 삭제를 수행하면 다시 온라인 로드해야 할 수 있습니다.
- GitHub Pages에 게시된 **코드**는 공개될 수 있지만 **학습 진도 데이터는 코드 저장소에 자동 공개되지 않습니다**.
- 처음 시작할 때 과목·목표·학습 기록은 비어 있습니다.

## 현재 제한사항

- 계정 로그인, 기기 간 자동 동기화, 푸시 알림, 특정 일자 휴일 지정, 드래그 정렬은 미지원
- 기록 차트는 서로 다른 단위가 섞일 수 있으므로 정확한 학습량의 과목 간 비교에는 사용하지 않습니다.
- iPhone Safari 실기기 설치 테스트는 이 환경에서 진행하지 못했습니다. 소스 구문과 앱 상태 로직 검사를 통과한 베타 버전입니다.

## 라이선스

이 프로젝트의 StudyFlow 웹앱 코드는 별도로 처음 작성했습니다. 사용자가 자유롭게 개인적으로 수정·배포할 수 있습니다.
